# 立て続けにメッセージを送る場合の動作確認

クライアントから、"hello"と"world"を連続して送った場合、サーバーは、

- "hello"と"world"を別々に受信するのか？
- "helloworld"として一つのメッセージとして受信するのか？

の検証。答えは、後者。

gemini の説明: https://gemini.google.com/app/7da70f6cf3895386

ネットワークプロトコル、OS、node 自身、の各段階でバッファリングしている。そのため、クライアントからは、"hello"と"world"が連続して送られた場合でも、サーバーはそれを一つのメッセージとして受信する。
